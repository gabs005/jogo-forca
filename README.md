# 🎯 Jogo da Forca em Python

Este é um dos meus primeiros projetos práticos desenvolvidos em Python! Trata-se do clássico Jogo da Forca, executado diretamente no terminal. O principal objetivo deste desenvolvimento foi consolidar os conceitos fundamentais da linguagem, aplicando lógica de programação e boas práticas de estruturação de código.

## 🧠 Conceitos Praticados

Durante o desenvolvimento, explorei recursos essenciais do ecossistema Python:

- **Sorteio Aleatório:** Utilização da biblioteca nativa `random` para selecionar dinamicamente a palavra secreta a cada nova partida.
- **Manipulação de Coleções:** Uso de listas e strings para gerenciar e atualizar as posições das letras descobertas e mascarar a palavra secreta.
- **Estruturas de Controle e Loops:** Implementação de laços `while` e condicionais `if/else` para gerenciar o fluxo do jogo, as tentativas do usuário e as regras de fim de jogo.
- **Validação de Inputs:** Tratamento de entradas do usuário para impedir erros causados por caracteres inválidos ou tentativas repetidas, melhorando a experiência do jogador.

## 🛠️ Tecnologias Utilizadas

- **Python 3** (Linguagem principal)
- **Git & GitHub** (Controle de versão e hospedagem do código)

## 🚀 Como Executar o Projeto

Caso queira testar o jogo na sua máquina, certifique-se de ter o Python instalado e siga os passos abaixo:

1. Clone este repositório:

   ```bash
   git clone https://github.com
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd jogo-forca
   ```

3. Execute o script do jogo:
   ```bash
   python forca.py
   ```
